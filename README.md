# 미션 - 자판기

# 기능 목록
**1. [입력] 자판기가 보유하고 있는 금액을 입력받는다.**
   - [예외 처리] 입력 금액이 정수 타입이 아닐 경우 예외 메시지를 출력하고 다시 입력받는다.

**2. [중간 과정] 입력받은 금액으로 동전을 무작위로 생성한다.**

**3. [출력] 자판기가 보유한 동전을 출력한다.**
     
**4. [입력] 상품명, 가격, 수량을 입력받는다.**
   - [예외 처리] 각 상품이 세미 콜론 외의 구분자로 구분되어 있을 경우 예외 메시지를 출력하고 다시 입력받는다.
   - [예외 처리] 상품 정보에 쉼표 외의 구분자가 포함될 경우 예외 메시지를 출력하고 다시 입력받는다.
   - [예외 처리] 상품 가격과 수량이 정수 타입이 아닐 경우 예외 메시지를 출력하고 다시 입력받는다.
   - [예외 처리] 상품 가격이 100원 이하일 경우 예외 메시지를 출력하고 다시 입력받는다.
   - [예외 처리] 상품 가격이 10원으로 나누어떨어지지 않을 경우 예외 메시지를 출력하고 다시 입력받는다.
   - [예외 처리] 상품 수량이 음수일 경우 예외 메시지를 출력하고 다시 입력받는다.
   - [예외 처리] 투입 금액이 정수 타입이 아닐 경우 예외 메시지를 출력하고 다시 입력받는다.
     
**5. [입력] 투입 금액을 입력받는다.**
   - [예외 처리] 투입 금액이 정수 타입이 아닐 경우 예외 메시지를 출력하고 다시 입력받는다.
   - [예외 처리] 투입 금액이 음수일 경우 예외 메시지를 출력하고 다시 입력받는다.

**6. [출력] 남은 금액을 출력한다.**
   - 남은 금액이 남은 금액이 상품의 최저 가격보다 적거나, 모든 상품이 소진된 경우 반복을 종료한다.

**7. [입력] 구매할 상품명을 입력받는다.**
   - [예외 처리] 존재하지 않는 상품일 경우 예외 메시지를 출력하고 다시 입력받는다.
   - [예외 처리] 남은 금액보다 해당 상품의 가격이 비싼 경우 예외 메시지를 출력하고 다시 입력받는다.
   - [예외 처리] 상품의 수량이 남아있지 않는 경우 예외 메시지를 출력하고 다시 입력받는다.

**8. [중간 과정] 해당 상품의 가격만큼 투입 금액을 차감하고, 상품의 수량도 차감한다.**
   - 투입 금액으로는 동전을 생성하지 않는다.(물건을 팔아도 해당 금액은 자판기에 누적되지 않음)

**9. [출력] 잔돈을 출력한다.**
   - 잔돈으로 반환할 수 있는 금액만 반환한다. (10, 50, 100, 500원 외의 단위들은 자판기에 남는다.)
   - 현재 보유한 최소 개수의 동전으로 잔돈을 돌려준다.
   - 남은 금액보다 잔돈이 적더라도 자판기에 존재하는 잔돈만 반환한다.
